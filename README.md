### ![MapFrontiers](https://alejandrocoria.games/projects/MapFrontiers/github_readme_logo.png)

MapFrontiers is an addon for JourneyMap that allows you to divide the map into regions and assign them names and colors.

![Panels showing the 3 frontier shapes and the list with collections](https://alejandrocoria.games/projects/MapFrontiers/territory_panels_2.png)

### API

MapFrontiers includes a public API for client and server plugins that want to create, update or observe frontiers. See the [MapFrontiers API quickstart](https://github.com/alejandrocoria/MapFrontiers-API#readme).
